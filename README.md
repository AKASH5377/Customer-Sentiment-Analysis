# Customer Sentiment Analysis using Machine Learning

## Overview
This project uses Natural Language Processing (NLP) and Machine Learning to classify customer reviews as Positive or Negative.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression

## Features
- Text preprocessing
- Sentiment classification
- TF-IDF feature extraction
- Positive and Negative review prediction

## Skills Demonstrated
- Machine Learning
- Natural Language Processing (NLP)
- Python Programming
- Text Classification

## Future Improvements
- Larger datasets
- Deep Learning models
- Real-time sentiment analysis
